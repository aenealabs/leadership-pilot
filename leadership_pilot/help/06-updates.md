# Weekly update

The AI drafts the update over this week's facts; code decides whether it can be sent.

## What is checked

Every sentence must cite at least one fact, cite only facts that exist, use only numbers
found in the facts it cites, and never state a status (status comes from the rules and is
shown beside the text). A sentence with a problem is flagged and blocks approval.

## Editing and approval

Edit any sentence; every edit is a new version, with the AI's draft kept as the first.
When nothing is flagged, approve the update. Its text cannot change after approval.

## Delivery

After approval, deliver it by Outlook (saved as a draft by default, or sent), a Teams
channel, or Slack, in a summary version for executives and a detailed one for product leads,
set per person on the distribution list. Delivery is simulated unless the app is set to live:
the exact payload is recorded and nothing leaves the machine.
